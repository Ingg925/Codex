# SVP 市场数据看板 MVP

这是 Marcus 的第一个可运行市场看板项目。**所有数字、KOL 名称、费用和交易表现均为虚构演示数据**，没有内部业务数据、密钥或外部依赖。

## 先看到看板：无需安装任何开发工具

1. 打开 https://github.com/Ingg925/Codex 。
2. 点击绿色 **Code → Download ZIP**，下载后解压。
3. 进入解压后的 `Codex-main` 文件夹，双击 `index.html`，用 Chrome、Edge 或 Safari 打开。
4. 你会看到绿色侧栏的“市场增长看板”和“模拟数据”标签。不要只下载 index.html；它依赖同目录中的 4 个 JS/CSS 文件。

这条路径适合电脑。手机预览 ZIP 内网页可能不能加载配套脚本，建议先在 Mac 或 Windows 电脑操作。仓库地址是代码页面，不是在线运行的看板地址；本项目尚未部署公网网站。

## 学习开发：准备环境并本地运行

### 第一步：安装 Node.js

从 https://nodejs.org/ 下载当前 LTS 安装包，用默认选项安装。打开 Mac 的“终端”，或 Windows 的 PowerShell，分别输入：

```sh
node --version
npm --version
```

应输出版本号。本项目要求 Node.js 20 或以上；无需 npm install、无需数据库、无需 OpenAI API Key。

### 第二步：进入项目文件夹

使用前面的 ZIP 路径，在终端输入 `cd `（后面留一个空格），把解压后的项目文件夹拖进终端，按回车。如果路径有空格，请用英文双引号包住，例如：

```sh
cd "/你的实际路径/Codex-main"
```

Windows 也可以在项目文件夹空白处右键“在终端中打开”。确认当前目录中能看到 package.json。

### 第三步：启动

```sh
npm start
```

看到“SVP 看板已启动”后，打开浏览器访问 http://localhost:3000 。保持终端开启；停止时按 Ctrl+C。`localhost` 只指正在运行项目的那台电脑，不能从另一台设备直接访问。

如果 3000 端口被占用，先关闭其他运行中的本项目终端。也可以改用 3001：Mac 输入 `PORT=3001 npm start`；Windows PowerShell 先输入 `$env:PORT=3001`，再输入 `npm start`，然后访问 http://localhost:3001 。

### 第四步：验证项目

```sh
npm test
npm run check
```

测试覆盖数据校验、筛选、金额与人数汇总、空数据、CSV 以及 API 错误处理。`check` 检查 JavaScript 语法。

## 看板怎么用

- 默认查看 2026-10-13 至 2026-10-26，演示数据完整范围是 2026-09-29 至 2026-10-26。
- 核心卡片：访问、注册、首充、首单、累计交易量、累计手续费、累计净入金、首单获客成本。
- 支持开始/结束日期、渠道、KOL、活动共同筛选；所有条件是 AND 关系。
- 试试渠道 X + KOL-A + 交易赛：应有 14 条聚合记录，访问 3,915，注册 801，首充 322，首单 212。
- 漏斗展示同一批访问用户的转化；趋势图可切换访问、注册、首充、首单。
- 渠道分析含首充/首单 CAC、费用、手续费与访问到首单转化率。CSV 仅导出当前筛选结果。
- 分享点击、受邀注册、受邀首充、受邀首单单列；它们不是人人都经过的漏斗步骤。
- 无匹配组合显示空状态；零分母显示“—”。点击“重置”恢复默认。

## 数据口径：读图前先看这里

日期筛选代表**首次访问获客批次**，不是全站交易发生日期。同一个账户仅属于一个首次访问日和一组归因维度，所以可以跨日相加。首充、首单是该批次截至 2026-10-26 的转化；交易量、手续费和资金流也是这些用户截至该日期的累计数。近期批次观察时间短，不能直接当作最终转化表现。

默认演示采用首次触点归因、Asia/Shanghai 时区和 USD。注册不等于连接钱包，首充不等于桥接到账，首单不等于提交订单；用户数为可识别账户，不宣称自然人数。市场费用按获客批次预分摊；CAC＝合计费用÷合计人数，不能平均各渠道的 CAC。手续费演示为未扣返佣。

7 日留存、与上一周期对比、真实埋点采集、登录权限和运营写入操作不属于本次 MVP，尚未实现。访问演示不会收集你的行为数据。正式接入与事件建议见 [接口契约](docs/DATA_CONTRACT.md)。
